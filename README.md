# Small-Scale Heat Exchanger Design and Experimental Analysis

This project involved designing, building and testing a small-scale heat exchanger using copper tubing, a pumped cold-water stream and a hot-water bath.

The system was designed in SolidWorks, instrumented using an Arduino UNO R4 Minima and four DS18B20 temperature sensors, and analysed using Python.

## Project Objectives

- Design a small-scale heat exchanger in SolidWorks
- Manufacture and assemble the heat-transfer system
- Measure temperature changes using Arduino sensors
- Determine water flow rate experimentally
- Analyse heat-transfer performance using Python
- Calculate Reynolds number, LMTD, heat-transfer rate and overall heat-transfer coefficient
