# Code

This folder contains the Python analysis code used for the heat exchanger project.

## Python

`heat_exchanger_analysis.py`

Used to:
- import the temperature data
- calculate flow rate and mass flow rate
- calculate heat-transfer rate
- calculate LMTD
- calculate overall heat-transfer coefficient
- calculate Reynolds number
- calculate heat exchanger effectiveness
- produce plots of the experimental results

## Data Acquisition

Temperature measurements were collected using an Arduino UNO R4 Minima and four DS18B20 temperature sensors.
